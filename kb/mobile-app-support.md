# Mobile App Troubleshooting

## Crashes after an update

Crash reports should include the device model, the operating system version and the app version shown under Settings > About. Most crashes on launch after an update are fixed by installing the latest release or reinstalling the app, which does not delete any synced data. Crashes that continue after a reinstall are logged as bugs with the crash report attached.

## Sync between mobile and web

Changes made on a phone sync to the web app as soon as the device is online, and pulling down on the main screen forces a sync. Changes made in offline mode stay on the device until the next successful sync.

## Notifications and uploads

Push notifications depend on both the in-app notification settings and the phone's system permissions, including focus and do-not-disturb modes. Photo uploads need photo library access and are limited to 25 MB per file.

## Display issues

Display problems such as unreadable text in dark mode are logged as bugs with a screenshot, and switching to the light theme is the temporary workaround.
